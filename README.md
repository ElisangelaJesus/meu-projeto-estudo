# Personal Bio - HTML Semântico


Este projeto é o ponto de partida do meu plano de estudos avançado para me tornar Desenvolvedora Fullstack Node.js. 
0 objetivo foi aplicar conceitos de **HTML5 Semântico** e **Acessibilidade**, garantindo que a estrutura do site seja interpretada
corretamente por motores de busca (SEO) e tecnologias assistivas.

markdown


## 🧠 Conceitos Aplicados
⁃ **Semântica:** Uso de tags como <header>`, `<main>`, `<section>` e `<footer>` em vez de `<div>` genéricas.
⁃ **Acessibilidade (A11y):** Implementação de atributos `alt em imagens e estrutura de títulos hierárquica (h1, h2, h3)
⁃ **Git Workflow:** Prática de commits atômicos (um commit para cada pequena funcionalidade concluída).


## 🛠️ Tecnologias e Ferramentas
- **HTML5** (Estrutura semântica)
- **Git** (Versionamento de código)
- **GitHub** (Hospedagem de repositório)
